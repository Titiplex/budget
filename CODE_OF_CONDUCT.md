# Code de conduite

## Notre engagement

Nous voulons que ce projet reste un espace accueillant, professionnel et utile pour toutes les personnes qui y contribuent, quel que soit leur niveau d’expérience, leur origine, leur identité, leur situation personnelle ou leur manière de contribuer.

Les échanges doivent rester centrés sur le projet, les faits techniques et l’amélioration de l’application.

## Comportements attendus

Les comportements attendus incluent notamment :

- rester respectueux, même en cas de désaccord ;
- expliquer les problèmes clairement, sans attaque personnelle ;
- accueillir les retours et les corrections ;
- documenter les décisions importantes ;
- signaler les bugs avec assez de contexte pour pouvoir les reproduire ;
- éviter les commentaires hors sujet, provocateurs ou dénigrants.

## Comportements refusés

Les comportements suivants ne sont pas acceptés :

- insultes, harcèlement, intimidation ou menaces ;
- attaques personnelles ou remarques discriminatoires ;
- publication d’informations privées sans consentement ;
- spam, trolling ou détournement volontaire des discussions ;
- pression pour obtenir une réponse immédiate ;
- divulgation publique de vulnérabilités exploitables avant correction.

## Application

Les mainteneurs peuvent modérer, masquer ou supprimer des commentaires, issues ou pull requests qui ne respectent pas ce code de conduite. Ils peuvent également limiter temporairement ou définitivement la participation d’une personne au projet.

Les décisions de modération doivent rester proportionnées, documentées quand c’est utile, et centrées sur la protection du projet et des contributeurs.

## Signaler un problème

Pour signaler un comportement problématique, contactez les mainteneurs via les canaux GitHub disponibles sur le dépôt. Pour une vulnérabilité de sécurité, utilisez la procédure décrite dans [`SECURITY.md`](SECURITY.md) et n’ouvrez pas d’issue publique contenant des détails exploitables.
